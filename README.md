# Cybersecurity Lab Write-ups — Hack The Box, Nmap, CTFs and Wargames

A collection of practical cybersecurity lab write-ups by **Nischal Dhakal**. I use this repository to document how I approach Hack The Box Academy modules, CTF challenges, Linux wargames, network enumeration, and other hands-on security exercises.

The goal is not to dump answers. Each write-up focuses on:

- the question or objective
- the command or technique used
- why the technique works
- how to interpret the result
- the mistakes and lessons that made the topic clearer

## Writing Principles

I write these notes mainly to remember how I approached a problem, where I became stuck, and what finally made the concept click. Passwords, flags, and sensitive information are excluded where publishing them would reduce the learning value or violate platform rules.

Lab addresses and results can change between sessions. Always use the target information assigned to your own authorized lab environment.
